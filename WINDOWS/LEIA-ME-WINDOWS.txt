O que eu SIM consegui deixar 100% pronto:

O QUE FALTA — E É SÓ ISSO — PARA GERAR O .EXE DE VERDADE:

1. Um computador (Windows, Mac ou Linux — qualquer um serve) com
   Node.js instalado (baixe grátis em nodejs.org, é só next-next-next).
2. Abrir uma janela de terminal dentro da pasta
   "projeto-instalador-windows".
3. Digitar estes dois comandos, um de cada vez:

      npm install
      npm run dist:win

4. Isso baixa o Electron (framework usado) automaticamente da internet
   e monta o instalador sozinho. Demora alguns minutos na primeira vez.
5. O arquivo final aparece em:
      projeto-instalador-windows/release/Instalar-LeuName-Gestao-1.0.0.exe

Esse .exe gerado é o que você distribui para os seus clientes.

Se você não tiver ninguém para rodar esses 2 comandos, qualquer
freelancer de TI resolve isso em poucos minutos — é um projeto Electron
padrão, nada exótico.

AVISO IMPORTANTE SOBRE O ÍCONE DO WINDOWS:
Como não existe uma assinatura digital (certificado de code signing) no
instalador ainda, o Windows SmartScreen pode mostrar um aviso de "editor
desconhecido" na primeira instalação em cada computador. Isso é normal
para instaladores não assinados e não impede a instalação — o usuário
clica em "Mais informações → Executar assim mesmo". Se quiser eliminar
esse aviso, é necessário comprar um certificado de assinatura de código
(passo para uma etapa comercial futura, não necessário agora).
