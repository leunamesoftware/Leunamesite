# Identidade visual EconoRota

- `icone.png` — ícone original (referência).
- `icone-play-store-512.png` — ícone da Play Store (512×512, fundo roxo).
- No app, o símbolo aparece **sem o quadrado de fundo** (`app/assets/images/logo_mark.png`; versão para fundo claro: `logo_mark_light.png`).
- `logo-horizontal.png` — logo horizontal (banners, site, Hotmart, Kiwify).

| Cor | Hex | Uso |
|---|---|---|
| Roxo | `#480082` | cor principal da marca |
| Verde | `#39FF14` | destaque, "Rota", botões de ação |
| Fundo | `#14062B` | fundos escuros (roxo bem escuro) |
| Roxo escuro | `#2A0859` | degradês do cabeçalho |
| Branco | `#FFFFFF` | textos e áreas de conteúdo |

Fontes: Montserrat (títulos) e Roboto (textos). Não usar azul nem vermelho como cor de marca
(vermelho é reservado para descontos e erros no app).
