# Material da Play Store — EconoRota

| Arquivo | Uso na Play Console |
|---|---|
| `icone-512.png` | Ícone do app (512×512) |
| `grafico-destaque-1024x500.png` | Gráfico de recurso (1024×500) |
| `capturas-play-store/` | Capturas de tela do celular (8, 1080×1920, na ordem de envio) |
| `todas-as-telas/` | Todas as telas (cliente, mercado, entregador e administração) para site, Hotmart e Kiwify |
| `simulacao-pagina-play-store.png` | Como a página da loja deve ficar (só referência, não enviar) |

As telas são do modo demonstração. A do mapa (`08-rastreio-mapa`) está sem o fundo do mapa porque o provedor de mapas só é configurado em produção — refaça essa captura no celular com o app publicado.
